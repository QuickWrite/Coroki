# Coroki
A collaborative text based diagram interface.
It is intended to be a simple (and collaborative) [Kroki][kroki] frontend for the web.

> [!IMPORTANT]
> This project is still under heavy development and cannot be considered "ready".

## Project structure
The project is a Go server with a [PostgreSQL][postgre] database which serves HTML/CSS/JS to the client directly.
The server is the single-source-of-truth for all operations and generates the HTML using code generated using
[Templ][templ] and accesses the database use code generated by [sqlc][sqlc].

### Dependencies
The main external dependencies are:

For the backend:
- [Go 1.26.3][go]:            _(The main programming language the backend is written in)_
- [Templ][templ]:             _(The templating language to generate the necessary HTML)_
- [sqlc][sqlc]:               _(The bindings generator between the database and the server code)_
- [PostgreSQL][postgre]:      _(The SQL-Database the data is stored in persistently and securely)_

For the frontend:
- [TypeScript][ts]:           _(The language the frontend logic is written in)_
- [Node.js][node]:            _(The runtime that is needed for compilation)_
- [PNPM][pnpm]:               _(The package manager that keeps track of the JS dependencies)_
- [ESBuild][esbuild]:         _(The bundler that compiles and bundles the TypeScript/CSS files into one for the web)_

There are some soft-dependencies that are useful for development, but are not needed:
- [GNU Make][make]:           _(A simple way to run all commands in a standardized way)_
- [Docker & Compose][docker]: _(Allows for the creation of development container)_

## Building
The project can be built using the `make` commands defined in the [Makefile](Makefile).

> [!NOTE]
> It is assumed that the project was set up already and the necessary dependencies were installed.

As the repository does not include the generated sqlc and templ files, these have to be generated first by the user.
This can be done using these commands:
```bash
# Generate the templ code
make templ
# Generate the sqlc code
make sqlc
```

As the generated files for the frontend are also not included in the repository, they also have to be generated using ESBuild:
```bash
# Generate the JS and CSS files for the frontend
make frontend
```

Now the application can be launched. But without the database, it will instantly crash. As such a PostgreSQL has to be started. This can be done using `docker compose`:
```bash
# If docker needs root-level permissions, use sudo in front of this command
make db-up
```

To now start the application, it is now possible to run the application:
```bash
# Runs the application using `go run`
make run
```

> [!TIP]
> To stop the database, you can use
> ```bash
> make db-down
> ```
